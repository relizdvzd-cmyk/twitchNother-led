# Twitch Followers LED — конструктор v5.1

Сайт для ESP32 (обычная ESP32 Dev Module) и светодиодной матрицы 8×32 на 4 модулях MAX7219 (FC-16). Добавляйте блоки **«Twitch — фолловеры»** и **«Свой текст»**, меняйте их порядок и индивидуальные параметры (скорость прокрутки и пауза), сохраняйте сценарий через USB на ESP32.

## Плата и библиотеки

- ESP32 Dev Module (не ESP32-C3/S3), Arduino-ESP32 core 2.x/3.x.
- MD_Parola, MD_MAX72XX (Library Manager в Arduino IDE).
- Подключение MAX7219: DIN → GPIO23, CLK → GPIO18, CS → GPIO5, VCC → 5V, GND → GND. Общая земля обязательна. При необходимости используйте подходящий 5V блок питания для матрицы.
- Файл прошивки: [`source/Twitch_LED_Builder_ESP32_v5_1.ino`](source/Twitch_LED_Builder_ESP32_v5_1.ino).

## Первое включение

1. Откройте `.ino` в Arduino IDE. Выберите **ESP32 Dev Module**, установите библиотеки и загрузите прошивку один раз через USB.
2. В браузере Chrome или Edge откройте опубликованный сайт по HTTPS.
3. Закройте Serial Monitor Arduino IDE, нажмите «Подключить ESP32» и выберите USB Serial (например, COM4).
4. Откройте вкладку «Устройство», укажите Wi-Fi 2.4 ГГц и пароль при необходимости (сохранённые настройки с v3 сохраняются, если память не стирали).
5. Откройте «Конструктор»: добавьте блоки, укажите логины Twitch/свой текст и сохраните сценарий на ESP32.
6. После сохранения отключите USB от ПК. Сценарий работает от обычного USB-питания.

## Особенности

- До 12 блоков, логин Twitch для каждого счётчика свой.
- Подписчики получаются через публичный сторонний сервис DecAPI без личного Twitch API ключа, обновление раз в 5 минут. Доступность данных зависит от этого сервиса.
- Настройки и сценарий сохраняются в NVS (Preferences) на ESP32.
- Поддерживается экспорт/импорт сценария в `.json`. **Пароль Wi-Fi не попадает в этот файл.**
- Русский текст сохраняется в исходном виде, но в стандартном шрифте матрицы **транслитерируется латиницей**. Реальное кириллическое отображение потребует отдельного шрифта.
- Конструктор можно редактировать без ESP32 (локальный черновик браузера); запись на устройство требует прошивку v5.1.
- Сайт является статическим; сервер для настройки ESP32 не нужен. Для доступа к USB нужен браузер с Web Serial и HTTPS.

## Публикация через GitHub Pages

В репозитории откройте **Settings → Pages → Build and deployment → Deploy from a branch → main → /(root) → Save**. Адрес будет `https://<имя>.github.io/<репозиторий>/`.

## Обновления прошивки

Раздел «Обновления» использует ESP Web Tools. Пока в `firmware/release.json` указано `"available": false`, автоматическая установка опубликованной версии **выключена**: сначала нужно собрать и проверить совместимый бинарный файл.

Если используете «Загрузить собственный .bin», выбирайте **только скомпилированное приложение** для точно той же ESP32 и той же схемы разделов памяти. Адрес приложения — `0x10000` (65536). При первом обновлении **не стирайте Flash**, иначе удалятся Wi-Fi и сценарий. Никогда не загружайте случайный `.bin`.

## USB-протокол v5.1 (115200 baud / Newline)

```text
VERSION
STATUS
PLAYLIST GET
PLAYLIST BEGIN
PLAYLIST ADD TWITCH pwgood 65 300
PLAYLIST ADD TEXT SEVMTE8= 65 300
PLAYLIST ADD DATE BERLIN 65 300
CLOCK
PLAYLIST COMMIT
PLAYLIST CANCEL
REFRESH
```

`PLAYLIST ADD TEXT` принимает текст в UTF-8, закодированный base64. При программной записи сначала отправляйте BEGIN, затем все ADD, потом COMMIT. Неполный сценарий отменяется командой CANCEL.

## Безопасность

Wi-Fi пароль передаётся по локальному USB только в ESP32. При ручном вводе `WIFI ...` не публикуйте журнал с паролем. HTTPS-запросы с ESP32 выполняются в прототипе без проверки сертификата (`setInsecure`) — для эксплуатации в чувствительной сети следует добавить проверку корневого сертификата. Веб-страница сама по себе не может подключаться к плате без разрешения браузера.

Интерфейс и обмен с имитированной ESP32 проверены; физическая прошивка v5.1 на пользовательской плате ещё не испытана. `firmware/release.json` не содержит готового `.bin` до реального теста.


## Новое в версии 5.1 — дата и проверка обновления

Добавлен блок DATE: «Сегодняшняя дата», формат `ДД.ММ.ГГГГ`. Данные времени ESP32 получает из NTP по Wi-Fi. До синхронизации показывается `--.--.----`, фиктивную дату устройство не рисует. Поддерживаются зоны `BERLIN` (CET/CEST), `MOSCOW` (UTC+3), `VLADIVOSTOK` (UTC+10) и `UTC`.

Для наглядной проверки прошивки при каждом включении дисплей один раз прокручивает `V5.1 DATE READY`, а команда `VERSION` отвечает `VERSION TWITCHLED 5.1 PLAYLIST2 DATE1`.

**Публикация прошивки.** GitHub Actions компилирует Arduino ESP32 sketch для классической ESP32 Dev Module, Flash 4МБ, стандартная схема разделов и загружает app-only BIN в `firmware/twitch-led-v5.1.bin`. Веб-установщик пишет его **только в раздел приложения `0x10000`**. Перед установкой убедитесь, что предыдущая прошивка была для той же платы и той же схемы разделов; выберите без стирания памяти, чтобы сохранить Wi-Fi и playlist. Если ранее использована нестандартная разметка, обновлять через сайт нельзя: используйте Arduino IDE с прежними параметрами.

Публикация сайта и бинарника сама по себе не доказывает работу на физическом устройстве.
