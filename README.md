# Twitch LED Logic v6.2 — статус стримера без Twitch API-ключей

**[Открыть визуальный конструктор v6.2](https://relizdvzd-cmyk.github.io/twitchNother-led/logic-v62.html)** · **[Безопасное обновление ESP32 v6.2](https://relizdvzd-cmyk.github.io/twitchNother-led/updater-v62.html)** · [Исходник](source/Twitch_LED_Logic_v6_2.ino) · [Тесты](tests/test_logic_v62.mjs)

Добавлены **«Стример: офлайн/онлайн»** (действие: показать «PWGOOD: ОНЛАЙН», «PWGOOD: ОФЛАЙН» или «НЕТ ДАННЫХ») и бирюзовое значение **«Стример онлайн?»** (логическое, для «если / иначе»). В выводе выбираются «ник + статус» или «только статус»; логин настраивается отдельно для каждого блока. Пример: «если [Стример онлайн? / pwgood] = [ИСТИНА] → показать ИДЁТ СТРИМ!». Статус можно сравнивать с ЛОЖЬ и комбинировать с другими сравнениями через И / ИЛИ. Неизвестный статус пропускает обе ветки условия, чтобы отсутствие сети не воспринималось как подтверждённый офлайн. Симулятор позволяет вручную переключать «Онлайн / Офлайн / Нет данных» и не делает реальных Twitch-запросов.

**Без Twitch API на устройстве:** ESP32 читает публичный адрес https://decapi.me/twitch/uptime/{login}?offline_msg=OFFLINE по HTTPS, без OAuth и Client-ID. Это сторонний сервис, который **сам** обращается к Twitch API; полная независимость от Twitch API не гарантируется. Проверка раз в 2 минуты с повтором через 30 секунд при ошибке; у DecAPI есть серверный кэш примерно 5 минут, поэтому показ может отставать. При ошибках — «НЕТ ДАННЫХ». TLS в этом экспериментальном скетче использует setInsecure() как v6.1: проверка сертификата отключена, до применения в ответственных задачах её следует включить.

**Исправление проверки USB (7 ноября 2026):** веб-конструктор больше не объявляет прошивку несовместимой из-за отсутствия ответа за 400 мс после открытия COM-порта. Команда VERSION отправляется несколько раз при запуске (ESP32 может перезапускаться от USB) и отдельно по кнопке «↻ Проверить версию прошивки» без перепрошивки или потери программы. Реальный ответ VERSION выводится в статусе и журнале диагностики. Если ответа нет, сайт сообщает «Нет ответа», а не ошибочно «Нужна v6.2». Запись программы всё равно блокируется до точного ответа VERSION TWITCHLED 6.2 SCRIPT2 LIVE1.

**Совместимость:** v6.2 использует SCRIPT2 LIVE1 и не отправляет новые команды старой v6.1. Сохраняются импорт JSON v5/v6/v6.1, настройки Wi-Fi/NVS, программы и защищённое обновление только APP для **классической ESP32 Dev Module 4 МБ**; **не подходит для ESP32-S3/LILYGO T-Energy S3**. Готовность бинарной прошивки проверяется установщиком по SHA-256, и до публикации пакета запись недоступна. Физический тест пока не проводился.

# Twitch LED Logic v6.1 — сравнение любых значений

**[Открыть Scratch-подобный редактор v6.1](https://relizdvzd-cmyk.github.io/twitchNother-led/logic-v61.html)** ·
**[Отдельный безопасный USB-обновлятор v6.1 для классической ESP32](https://relizdvzd-cmyk.github.io/twitchNother-led/updater-v61.html)** ·
**[Исходник](source/Twitch_LED_Logic_v6_1.ino)** ·
**[Предыдущая Logic v6.0](logic-v6.html)** ·
**[Классическая v5.5](index.html)**.

## Новая модель данных

Блоки **вывода** остаются действиями: вывод текста, Twitch, дата/время, пиксели, ожидание, повторение. Отдельные бирюзовые блоки **значений** можно помещать в левый или правый слот условия: день недели, дата, время, час как число (0–23), фолловеры Twitch, ник Twitch, Wi-Fi, текстовый литерал, числовой литерал, логическое значение.

Пример: `если [ДЕНЬ НЕДЕЛИ / БЕРЛИН] = [ТЕКСТ / СУББОТА] → показать «ВЫХОДНЫЕ!!»`. Данные сравниваются во время исполнения программы, а не в момент её создания; имена дней сверяются без учёта регистра, включая русские буквы и Ё. При отсутствии NTP или актуальных данных Twitch условие с таким значением считается ложным.

Операторы `=`, `≠`, `>`, `≥`, `<`, `≤`, `содержит` работают с соответствующими типами: числовые неравенства только для чисел; поиск вхождения только для текста; булевы значения имеют равенство/неравенство. Смешивание несовместимых типов блокирует запись программы на устройство. В один `если` можно добавить второе сравнение с объединением через **И / ИЛИ**; более сложную логику получаем вложенными `если`.

## Вставка и перетаскивание

- Перетащи **команду из палитры** на «＋ вставить сюда» в корневой программе или внутри `ТО`, `ИНАЧЕ`, `повторить`.
- Перетащи **репортёр значения из палитры** прямо в левое/правое гнездо сравнения. Второе гнездо автоматически получает совместимый тип значения.
- Перетащи за ⠿ **уже созданную команду** в другую часть программы; если перетащить блок вывода текста, часов или Twitch в гнездо сравнения, в нём создаётся соответствующее значение, а сам вывод остаётся на месте. Для Twitch это *число фолловеров*.
- Без мышиного drag-and-drop редактор тоже работает: выбери гнездо, нажми значение из палитры или выбери его через список; «＋ вставить сюда» и ↑↓ доступны для клавиатуры/сенсорных устройств.

## Прошивка и ограничения

Новый протокол **SCRIPT2** отличается от SCRIPT1 в v6.0. USB-передача новой программы разрешается только при ответе `VERSION TWITCHLED 6.1 SCRIPT2 ...`. Сравнения сериализуются в инструкции `IFCMP`/ `IFCMP2`; на плате их исполняет собственный автономный интерпретатор. Поддерживаются 1–2 сравнения на блок, до трёх уровней вложения, максимум 42 инструкции и до 48 байт UTF-8 в текстовом операнде.

Классическая ESP32 Dev Module (4MB, стандартная разметка): отдельный веб-мастер проверяет плату, SHA-256 образа и MD5 таблицы разделов, пишет только APP с `eraseAll:false`, затем проверяет MD5 записи. Прежние NVS/плейлист v5.x не перезаписываются; `SCRIPT STOP` возвращает классический сценарий. Сохрани JSON-проект перед обновлением. **Прошивка v6.1 и новый установщик ещё не прошли испытание на физической плате.**

**LILYGO T-Energy S3 (ESP32-S3, 16 MB) не поддерживается этим установщиком.** Ей необходимы другой образ и отдельная проверка Flash. Страницу конструктора и симуляцию можно использовать без прошивки устройства.

# Twitch LED Logic v6 — визуальное программирование в стиле Scratch

**Экспериментальный редактор:** https://relizdvzd-cmyk.github.io/twitchNother-led/logic-v6.html  
**Отдельный защищённый USB-обновлятор v6.0 (только ESP32 classic 4MB):** https://relizdvzd-cmyk.github.io/twitchNother-led/updater-v6.html  
**Рабочая классическая версия v5.5:** https://relizdvzd-cmyk.github.io/twitchNother-led/  
**Исходник автономного движка:** [source/Twitch_LED_Logic_v6.ino](source/Twitch_LED_Logic_v6.ino)  
**Автоматическая проверка:** [ci-logic-v6.yml](.github/workflows/ci-logic-v6.yml)

## Что меняется
Вместо плоского списка сообщений теперь **программа из вложенных блоков**. Управление похоже на Scratch: перетаскивание за ⠿, вставка через «＋ вставить сюда» и кнопки ↑ ↓ для работы без drag-and-drop.

- **Вывод:** показать текст с подстановками, Twitch («ник + число» либо «только число»), дата/время/день недели, собственная пиксельная картинка (до 4 кадров).
- **Логика:** ждать 100–30 000 мс, повторить 1–10 раз, «если / иначе».
- **Условия:** Wi-Fi подключён, количество фолловеров канала ≥ N, местный час в заданном часовом поясе ≥ N.
- **Событие:** при включённом устройстве вся программа выполняется по кругу (аналог Scratch «всегда»).
- **Динамическое соединение значений:** в блоке «показать текст» допускаются `{followers:pwgood}`, `{time:BERLIN}`, `{date:BERLIN}`, `{weekday:VLADIVOSTOK}`. В отличие от обычного блока «Соединение», значения подставляются непосредственно перед показом.
- **Режим симуляции** в браузере с матрицей 8×32; Twitch = демонстрационное число 475070, Wi-Fi считается подключённым — реальные значения меняются только на ESP32.
- **Проект JSON:** сохраняется локально, есть импорт и экспорт; поддерживается импорт старых плоских сценариев v5, при этом соединённые надписи преобразуются в одну строку с подстановками.
- **Программирование через USB:** команды SCRIPT BEGIN / ADD / COMMIT / RUN, запись **только при подтверждённой поддержке SCRIPT1** в версии прошивки. Wi-Fi пароль не сохраняется в браузере.

## Важное про прошивку
- v6 создана как **отдельная экспериментальная ветка** для классической ESP32 Dev Module, **4 МБ Flash**, DIN=23, CLK=18, CS=5. GitHub Actions компилирует её и проверяет исходники без автоматической установки на устройство.
- **Рабочую v5.5, её веб-обновлятор, разделы Flash и NVS не изменяли.** Не нужно прошивать v6, чтобы попробовать редактор и симуляцию. Если устанавливать бета-прошивку вручную через Arduino IDE, сначала экспортировать старый сценарий в JSON и не выбирать Erase All Flash.
- При первом запуске v6 читает сохранённые старые блоки; без нового скрипта продолжает их исполнять. Программы v6 хранятся отдельно, команда **SCRIPT STOP** отключает новую логику и возвращает старый сценарий.
- **Нельзя** использовать старые веб-обновляторы v5.x для LILYGO T-Energy S3: у неё ESP32-S3, 16 МБ Flash и другая разметка. Для неё будет нужна отдельная сборка.
- Отдельный веб-обновлятор v6 использует прежнюю проверенную схему: SHA-256 образа, проверка типа ESP32 и Flash 4 МБ, MD5 загрузчика/таблицы разделов, запись **только APP по 0x10000** с `eraseAll:false`, контрольная MD5 после записи. Он не перепрошивает загрузчик и не стирает NVS. **Сам образ v6 и обновлятор на физической плате пока не проверены**: перед установкой сохрани JSON; не использовать для LILYGO T-Energy S3.

# Twitch Followers LED — конструктор v5.5

**[Открыть конструктор](https://relizdvzd-cmyk.github.io/twitchNother-led/)** ·
**[Обновить классическую ESP32 до v5.5](https://relizdvzd-cmyk.github.io/twitchNother-led/updater-v55.html)** ·
**[Исходник v5.5](source/Twitch_LED_Builder_ESP32_v5_5.ino)** ·
**[Пример сценария v5.5 (JSON)](examples/v55-demo-playlist.json)**.

## Новые блоки в v5.5
- **Часы** в формате `ЧЧ:ММ` и **день недели** на русском: часовые пояса Берлин, Москва, Владивосток/Хабаровск, UTC. NTP через Wi-Fi, корректная дата/время только после синхронизации.
- **Счётчик Twitch** — один блок с переключателем формата: `PWGOOD: 475070` или только `475070`. Отдельные кнопки «Ник» и «Число фолловеров» убраны: обычный текст подходит для статичного ника. Для совместимости старые сериализованные типы `NICK` и `COUNT` прошивка по-прежнему понимает.
- **Пиксельный рисунок / анимация** (`PIXEL`): редактор 8×32 прямо в браузере, до четырёх кадров в одном блоке. Отдельно задаются интервал смены кадров (100–900 мс) и длительность показа (500–9000 мс). `64` HEX символа на кадр (32 колонки по 8 пикселей), кадры отделяются точкой. Редактирование мышкой или пальцем, добавление/удаление кадров, инверсия и очистка.
- **Соединение ↔** из v5.4 осталось: можно объединить текст, ник, число, дату/время в одну прокрутку. Пиксельные кадры показываются отдельно и не соединяются с текстом.

Старые сценарии v5.3/v5.4 совместимы по протоколу и Preferences/NVS. Формат JSON теперь `schema:3`, импорт прежних JSON поддерживается. Список ограничен 12 элементами, включая соединители.

## Прошивка и безопасное обновление
- **Классическая ESP32 Dev Module, Flash 4MB, стандартная разметка** — веб-мастер v5.5 пишет **только APP по `0x10000`**, с `eraseAll:false`. Перед записью проверяются тип контроллера, объём Flash, SHA-256 BIN, MD5 загрузчика и таблицы разделов. Полное стирание Flash не выполняется.
- Новая v5.5 успешно проходит CI-компиляцию и автоматические проверки конструктора; **на физической плате v5.5 ещё нужно испытать**. Рабочие v5.3/v5.4 и их мастера сохранены.
- **LILYGO T-Energy S3** — *не использовать этот обновлятор*: ESP32-S3 и разметка 16MB требуют отдельного безопасного установщика. Функции конструктора готовы к переносу на S3, когда плата появится.
- До установки v5.5 можно редактировать и экспортировать новые блоки в JSON, но сайт не отправляет их на ESP32 с прошивкой младше v5.5.

**Резервный конструктор:** [v5.4](classic-v54.html). **Ранее испытанный веб-мастер:** [v5.3](updater.html).

# Twitch Followers LED — конструктор v5.4

**Сайт:** https://relizdvzd-cmyk.github.io/twitchNother-led/  
**Обновление v5.4:** https://relizdvzd-cmyk.github.io/twitchNother-led/updater-v54.html  
**Рабочая контрольная версия:** v5.3 (проверена на физической ESP32); v5.4 прошла CI, испытание на устройстве ожидается.

## Конструктор v5.4: JOIN

Элемент **«Соединение ↔»** вставляется строго между **двумя обычными блоками** (Twitch, текст, дата).
Вместо двух последовательных прокруток показывается одна объединённая строка:

```text
Текст «Подписчики» → JOIN (пробел) → Twitch «pwgood»
Результат: Подписчики PWGOOD: 475070
```

Доступны два разделителя: `SPACE` (один пробел) и `NONE` (без пробела). Разделитель не добавляет паузу. **Скорость прокрутки и пауза берутся у первого блока**, пауза — только в конце объединённой строки. Для цепочки `TEXT → JOIN → TWITCH → JOIN → DATE` действует та же логика. Соединитель занимает одно из 12 мест сценария.

Протокол USB: `PLAYLIST ADD JOIN SPACE 65 0`. В NVS соединитель хранится как тип 3; прежние сценарии v5.3 остаются совместимы. На старой прошивке сайт позволяет подготовить JSON, но блокирует отправку JOIN на ESP32. Проверка подключения и сохранности Wi-Fi — как в v5.3.

**Безопасность обновления:** веб-установщик v5.4 использует отдельный manifest и проверяет модель **классической ESP32, 4 MB** и MD5 штатной таблицы разделов; записывает только приложение по `0x10000` с `eraseAll:false`. Для заказанной **LILYGO T-Energy S3** он **не подходит**; туда позже потребуется отдельная прошивка и загрузчик.

**Исходный код:** [source/Twitch_LED_Builder_ESP32_v5_4.ino](source/Twitch_LED_Builder_ESP32_v5_4.ino).  
**Старая испытанная сборка v5.3:** [исходник](source/Twitch_LED_Builder_ESP32_v5_3.ino) · [мастер](updater.html).

# Twitch Followers LED v5.3 — обновление через сайт

Конструктор для ESP32 Dev Module + MAX7219 8×32. В версии **5.3** сохранены кириллица, дата (NTP), Twitch и пользовательские блоки. Контрольное сообщение на матрице: `V5.3 WEB OK`, команда `VERSION`: `VERSION TWITCHLED 5.3 PLAYLIST2 DATE1 CYRILLIC1 WEBUPDATE1`.

## Два способа установки

**Обновление по USB с сайта:** открой вкладку «Обновления» → «Открыть мастер обновления v5.3», затем проверь плату и подтверди запись. Мастер использует `esptool-js` и **записывает только APP по адресу `0x10000`**, принудительно `eraseAll:false`. Он предварительно проверяет SHA-256 скачанного файла, модель чипа (классическая ESP32), 4MB Flash, байт заголовка загрузчика, таблицу разделов и размер APP, затем сверяет MD5 непосредственно во Flash. **Загрузчик, таблица разделов, NVS и Wi-Fi не стираются и не перезаписываются.** Никакого выбора произвольного BIN в интерфейсе нет.

**Восстановление через Arduino IDE:** файл `source/Twitch_LED_Builder_ESP32_v5_3.ino`. Выбирай ESP32 Dev Module (только если это действительно твоя плата), Flash Size 4MB, Flash Mode DIO, Partition Scheme Default. Записывай обычной кнопкой «Загрузить», изначально без Erase All Flash. Это надёжная запасная процедура после сбоя питания или ошибки прошивки.

## Резервный комплект

GitHub Actions компилирует APP и публикует отдельно образы загрузчика `0x1000`, таблицы разделов `0x8000`, `boot_app0.bin` `0xE000` и APP `0x10000`. Они предназначены **только для восстановления** после проверки конкретной платы. На сайте нет кнопки полной переустановки. Не объединяй эти образы в единый BIN с заполнением `0xFF` и записью с нуля: это может стереть NVS и настройки Wi-Fi.

## Неподдерживаемое железо и ограничения

- Требуется классическая ESP32 (не C3/S2/S3), Flash 4MB и стандартная разметка ESP32 Arduino.
- Сохранение сценария в JSON перед обновлением — рекомендуется.
- Только Chrome/Edge и HTTPS; монитор порта должен быть закрыт.
- Проверка прошивки на реальной пользовательской плате пока не проводилась. Успешные браузерные тесты не гарантируют отсутствия аппаратных/USB-сбоев.
- Если предустановленные таблица разделов или размер памяти отличаются, обновлятор останавливается **до записи**. Используй Arduino IDE.
- При отключении USB во время записи приложение может перестать загружаться. Загрузчик при этом остаётся, восстановление возможно через Arduino IDE.
- Режим OTA по Wi-Fi в этой версии не реализован: обновление через сайт требует USB.
