# Twitch LED — настоящая кириллица, версия 5.2

Матрица MAX7219 8×32, ESP32 Dev Module. Рекомендуемая прошивка для пользователя: **v5.2**.

## Новое
- Русские заглавные и строчные буквы **А–Я, а–я, Ё, ё** отображаются пикселями непосредственно на LED-матрице, а **не транслитерируются**.
- Пользовательский пиксельный шрифт 5×7/6×7/7×7 создаётся в коде MD_MAX72XX Font v2 (байты CP1251); нормальный русский UTF-8 сохраняется в памяти и передаётся через USB без изменений.
- Предпросмотр браузера использует **те же рисунки букв**, что и ESP32.
- Поддерживаются латинские буквы, цифры и основные знаки препинания.
- **v5.1 → v5.2** не меняет NVS namespace `twitch-led`, USB-протокол и структуру сохранённых блоков.

## Как установить
1. Скачай `source/Twitch_LED_Builder_ESP32_v5_2.ino`, открой в Arduino IDE, выбери ESP32 Dev Module (если это твоя плата), Flash 4 MB, DIO, PartitionScheme=Default.
2. Установи библиотеки MD_Parola и MD_MAX72XX через Менеджер библиотек.
3. Подключи ESP32, нажми обычную «Загрузить». **Не выбирай Erase All Flash**.
4. После перезагрузки матрица однократно покажет `V5.2 RUS READY`. В мониторе порта на 115200 команда `VERSION` ответит `VERSION TWITCHLED 5.2 PLAYLIST2 DATE1 CYRILLIC1`.
5. Открой сайт GitHub Pages, нажми Ctrl+F5 и отправь в конструкторе блок `Привет, мир!` или `Ёжик в тумане`.

## Важное о прошивке через сайт
**Прямая установка бинарного `.bin` на сайте отключена**, поскольку прежний установщик мог стереть загрузчик и вызывать `invalid header: 0xffffffff`. До разработки и проверки полнофункционального пакета через браузер не прошиваем. Сайт служит для настроек, предпросмотра и USB-команд.

## Поддержка
Русские буквы, включая Ё/ё, полностью поддерживаются. Различные Unicode-символы (эмодзи, иероглифы) не поддерживаются и отображаются знаком `?`. Текст ограничен 120 байт UTF-8 на один блок (примерно 60 кириллических символов).

## Испытания
Глифы проверяются программно для 66 русских букв, шрифтовая таблица сверяется с превью и проходит компиляцию в GitHub Actions. Финальная проверка на матрице пользователя ожидается после загрузки `.ino`.
