Создай сценарий, затем подключи ESP32 с прошивкой v5.2.

Кириллица поддерживается с v5.2, дата — с v5.1, а элемент «Соединение» требует новую прошивку v5.4. На старой прошивке можно собрать и сохранить JSON-черновик, но записать соединённый сценарий на ESP32 нельзя. Веб-обновлятор для классической ESP32 использует проверку памяти и не стирает всю Flash.

Подключение к ESP32

Подключи плату USB-кабелем и закрой «Монитор порта» Arduino IDE. В окне выбора выбери USB Serial (например, COM4).

Безопасное обновление через USB

Новый мастер обновления использует esptool-js и обновляет только приложение. Перед записью проверяет ESP32, Flash 4 МБ, загрузчик и раздел приложения, а после — контрольную сумму. Команды полной очистки Flash нет.

Важно: сперва сохрани сценарий в JSON во вкладке «Конструктор». Закрой монитор порта и отключи ESP32 в разделе «Устройство». Не отключай USB во время записи. Работает только с классической ESP32 Dev Module, 4 МБ, с разметкой по умолчанию.
Открыть мастер обновления v5.3Скачать v5.4 для Arduino IDE

Ранее установленные v5.1/v5.2 поддерживаются при совпадающей схеме разделов. При несовместимой плате или разметке новый мастер остановится до записи. Предыдущая v5.3 была испытана на реальной ESP32; для v5.4 проверка на твоём устройстве ещё впереди. Старый мастер v5.3 пока доступен.

Ручная команда

Например, HELP или STATUS. Пароль Wi-Fi сюда не вводи.

Страница работает без серверного приложения. Настройки передаются прямо по USB; счётчик обращается к стороннему сервису DecAPI. Для Web Serial и установки прошивок нужен Chrome/Edge на компьютере и HTTPS. Сценарий хранится на ESP32; Wi-Fi остаётся на устройстве, даже когда компьютер отключён.
